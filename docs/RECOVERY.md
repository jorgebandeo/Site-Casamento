# Recuperação do projeto

O repositório original preservou uma fase inicial real do site: `index.html`, `style.css`, `script.js`, imagens, contador regressivo, autocomplete de convidados e integração com Google Sheets.

As evoluções posteriores — páginas adicionais, PHP/MySQL, lista de presentes mais completa e Pix — não estavam integralmente versionadas e foram reconstruídas para o portfólio.

A estratégia desta branch é preservar o histórico antigo e registrar a reconstrução como uma nova etapa do mesmo projeto, em vez de apagar os commits anteriores.
